Selected Projects

001

Time-Sensitive Network Scheduling in Linux in progress

Project module at TU Berlin's Telecommunication Networks group (TKN). I'm integrating TSNSCHED, an ILP-based schedule generator, into iTSN, an open-source Linux framework for IEEE 802.1 Time-Sensitive Networking. The computed schedules become Linux TAPRIO (802.1Qbv time-aware shaper) configurations, tested in the mininet network emulator.

Citizen Speak 1st place · AIESEC hackathon

A civic reporting app prototype built with my team at the AIESEC Maghreb4SDGs hackathon in Bizerte, Tunisia. Citizens photograph an infrastructure problem (a pothole, a broken street lamp) and the report goes straight to the municipality. Others can confirm reports, suggest fixes or donate toward repairs. I set up Firebase for accounts, data and photo storage and wired up the API integration.
